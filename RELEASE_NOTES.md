#### 1.0.0 September 9th 2026 ####

- Initial release of the Centra Distributed Application Framework for .NET 10.
- Native in-process performance with zero sidecars and zero-allocation execution paths.
- CNCF CloudEvents v1.0 binary and structured mode messaging with W3C distributed tracing context propagation.
- Virtual actors with sequential turn-based execution, timers, state management with ETags, and distributed reminders.
- Durable workflows and distributed sagas with reverse (LIFO) compensation.
- Distributed state stores with optimistic concurrency and transactional batching.
- Distributed mutual exclusion locks with automatic lease renewals and heartbeats.
- Comprehensive production and test providers: In-Memory, Redis, PostgreSQL, RabbitMQ, SQL Server, Azure Service Bus, and Azure Cosmos DB.
- Central Control Plane with real-time SSE streaming topology sync and component governance.
- .NET Aspire hosting extensions and multi-instance orchestration.
